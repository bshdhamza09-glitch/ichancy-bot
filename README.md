# Ichancy-style Telegram bot — المرحلة الأولى

يحتوي على القائمة الرئيسية كما في الصورة، ورسالة ترحيب متحركة `welcome.gif`، وأزرار عاملة بوضع تجريبي، وقاعدة SQLite للإحالات. لا يتصل حالياً بخدمات Ichancy ولا ينفذ أي عمليات مالية.

## التشغيل

1. ثبّت Python 3.11+.
2. نفّذ `pip install -r requirements.txt`.
3. انسخ `.env.example` إلى `.env` وأدخل توكن بوتك الخاص في `BOT_TOKEN`، ولا تشاركه مع أحد.
4. نفّذ `python bot.py`.

## الأيقونات المتحركة في الأزرار

ملف `bot.py` يحتوي على `CUSTOM_EMOJI_IDS`. للحصول على رموز مخصصة داخل الأزرار، تحتاج إلى معرفات Custom Emoji صحيحة وإصدار Bot API ومكتبة aiogram يدعمان `icon_custom_emoji_id`، إضافة إلى أي شروط يفرضها تلغرام. إذا لم تتوفر، تظهر الإيموجيات العادية تلقائياً. الرسالة المتحركة تعمل من ملف GIF المرفق دون الحاجة لهذه المعرفات.

## لاحقاً

ربط Ichancy يتطلب API رسمي موثّق وموافقة صاحب حساب الوكيل، مع اختبار العمليات قبل تفعيلها. لا تستخدم مفاتيح حقيقية داخل الكود أو المحادثة.
