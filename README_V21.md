# Sheikh V21 — سحب الرصيد الداخلي
- القائمة: سيريتل كاش، شام كاش (SYP/USD)، USDT وحوالات مالية (الأخيران غير مفعّلين حتى إضافة بيانات التنفيذ).
- سيريتل: حد أدنى 400 وحد أقصى 50000 ليرة سورية جديدة؛ رسوم 10%.
- شام كاش SYP/USD: رسوم 10%؛ USD يعرض الرصيد ويقبل المبلغ بالدولار وفق سعر الصرف الإداري `dollar_rate` المحفوظ لحظة تقديم الطلب.
- يحجز المبلغ الإجمالي من رصيد البوت عند الطلب؛ رفض الأدمن يعيده كاملاً؛ الموافقة تسجل إرسالاً يدوياً ولا تنفذ التحويل بنفسها.
- حساب شام كاش المعتمد هو `sham_verified` من إيداع سابق وافقت عليه الإدارة. دون عنوان موثق يمكن تقديم طلب بعنوان يدخله المستخدم، لكن يجب التحقق منه يدوياً قبل أي صرف.
- تذهب طلبات السحب إلى DEPOSIT_CHAT_ID وإلى حسابات ADMIN_IDS عند إمكان مراسلتها.
- يجب أن يضغط الأدمن زر الموافقة **فقط بعد إرسال الحوالة خارج البوت**. الموافقة لا تعني أن المال انتقل تلقائياً.
- التحقق التلقائي من إيداعات شام كاش والتحويلات مؤجل حتى توفر API رسمي وموافقة الربط.
- اختبروا العمليات بأرصدة اختبار قبل استخدام أموال حقيقية. لم يُجر اختبار حي على تلغرام.
