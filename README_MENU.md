# Sheikh V10 — Telegram Menu

تم إضافة قائمة الأوامر الرسمية إلى زر Menu:
- `/start`: القائمة الرئيسية.
- `/balance`: رصيد المستخدم الداخلي ونقاط الولاء.
- `/cancel`: إلغاء حالة الإدخال الجارية دون تنفيذ العملية.

يدعم أيضاً النصوص `/رصيدي` و`/الغاء العملية الحالية` داخل المحادثة، لكن أسماء الأوامر المعروضة في Telegram Menu يجب أن تكون لاتينية وبدون مسافات.

الخطوات: ارفع محتويات هذا المجلد إلى GitHub ثم انشر على Railway. احتفظ بمتغيرات البيئة وقاعدة البيانات الدائمة. عند تشغيل البوت سيتم تحديث قائمة الأوامر تلقائياً.

ملاحظة: `/cancel` لا يلغي طلب إيداع سبق إرساله للإدارة؛ يوقف فقط عملية إدخال البيانات الجارية. لا توجد عمليات مالية جديدة في هذا التحديث.
